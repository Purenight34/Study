### 상단 - Queue
담당 : 권은준

Queue는 먼저 들어온 것을 먼저 내보내는 문제이다.

문제
입력으로 숫자를 넣으면 리스트 맨 뒤에 들어가게 한다.
출력을 치면 리스트 맨 앞에 있는 것이 출력되게 한다.

인풋
- '입력' -> '내용' 할 수 있게 
- '내용' 
- '출력'

아웃풋
- '입력' 입력시 내용을 넣을 수 있게 하고, 내용을 넣으면 리스트 맨 뒤에 추가
- '출력' 입력할 경우 리스트 맨 앞 출력
### 중단 - 의사코드
입력 함수
    이 함수가 불렸을 때 내용을 리스트 마지막에 추가한다.
    마지막 인덱스 += 1

출력 함수
    이 함수가 불렸을 때 먼저 들어왔던 수를 출력한다.
    첫번째 인덱스 += 1

풀 넘버 함수
    이 함수를 불렀을 때 새로운 리스트(기존 리스트 크기의 1.25배)를 만들고 
    기존 리스트를 순차적으로 넣는다.
    첫번째 인덱스를 = 0
    마지막 인덱스를 = len(기존 리스트)
    기존 리스트 = 새로운 리스트

리스트 생성 = [None] * 3
반복문
  Question = input("무엇을 할까요? ")
  조건문으로 Question이 입력이면 내용을 받아 입력 함수를 불러온다.
  Question이 출력이면 출력 함수 호출
  그 외에는 잘못된 입력입니다 출력후 break
