### 상단 - 담당자와 설명
담당 : 권다빈

Stack은 가장 나중에 들어온 것을 먼저 내보내는 문제이다.

**문제**
문자열에는 (와 ) 두 종류의 괄호가 포함되어 있다.
괄호가 올바르게 짝을 이루고 있는지 확인하는 프로그램을 작성하시오.

괄호는 다음과 같은 경우 올바르다고 판단한다.
(가 나오면 괄호를 연다.
)가 나오면 가장 최근에 열린 (와 짝을 이룬다.
닫는 괄호 )가 나왔을 때 짝을 이루는 (가 없다면 올바르지 않다.
문자열의 모든 문자를 확인한 뒤 열린 (가 남아 있다면 올바르지 않다.

첫째 줄에 괄호 문자열이 주어진다.
문자열의 길이는 1 이상 100 이하이다.
문자열에는 (와 )만 주어진다.

문자열이 올바른 괄호라면 YES, 그렇지 않다면 NO를 출력한다.

### 중단 - 의사코드

문자열을 변수에 저장
문자열에서 뽑은 괄호를 저장할 리스트 선언

for ch in 문자열:
    if ch가 ( 이면:
        괄호 리스트에 ( 추가
    else:
        if 괄호 리스트가 비어 있으면:
            올바르지 않은 괄호라고 판단 (for문 빠져나가기)
        else:
            괄호 리스트의 마지막 ( 제거
else: 즉, for문이 정상적으로 수행되었을 경우
    if 괄호 리스트가 비어 있으면:
        YES 출력
    else:
        NO 출력
