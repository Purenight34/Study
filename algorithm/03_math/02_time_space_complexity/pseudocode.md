
## 13. Math - Time / Space Complexity

담당 : 고근우

### 시간 복잡도(Time Complexity)

**입력 데이터의 크기 `N`이 증가할 때, 알고리즘의 실행 시간이 얼마나 증가하는지 나타내는 개념**

실제 실행 시간을 초 단위로 계산하는 것이 아니라, **연산이 얼마나 많이 반복되는지**를 기준으로 표현한다.

대표적으로 **Big-O 표기법**(빅오)을 사용한다.

| 시간복잡도 | 간단한 의미 | 예시 |
|---|---|---|
| `O(1)` | 데이터가 늘어나도 거의 동일 | 리스트 인덱스 접근 |
| `O(N)` | N만큼 반복, 데이터 수만큼 증가 | 반복문 1개 |
| `O(N²)` | N × N만큼 반복, 데이터가 증가하면 연산량이 크게 증가 | 이중 반복문 |
| `O(log N)` | 데이터가 늘어나도 연산량이 조금씩 증가 | 이진 탐색 |
| `O(N log N)` | 효율적인 정렬에서 자주 등장 | 병합 정렬 |

예를 들어:

```python
for i in range(n):
    print(i)
```

`n`개의 데이터를 한 번씩 확인하므로

```text
시간복잡도 → O(N)
```

반면,

```python
for i in range(n):
    for j in range(n):
        print(i, j)
```

바깥 반복문 `N번` × 안쪽 반복문 `N번`이므로

```text
N × N = N²
시간복잡도 → O(N²)
```

### 공간 복잡도(Space Complexity)

**알고리즘을 실행하면서 추가로 얼마나 많은 메모리를 사용하는지 나타내는 개념**이다.
공간 복잡도 역시 Big-O 표기법을 사용

예를 들어:

```python
arr = [1, 2, 3, 4, 5]
```

```python
def solution(n):
    a = 10
    b = 20

    n이 아무리 커져도 a, b 정도의 고정된 공간만 사용

    O(1)
```
```python
def solution(n):
    arr = []

    for i in range(n):
        arr.append(i)



    N이 증가할수록 arr에 저장하는 데이터도 증가

    N = 10    → 10개 저장
    N = 100   → 100개 저장
    N = 1000  → 1000개 저장

    공간 복잡도 → O(N)

```   
```
O(1)  → 입력이 커져도 추가 메모리가 거의 일정
O(N)  → 입력 크기에 비례해서 추가 메모리 증가
O(N²) → N × N 크기의 메모리가 필요
```

데이터가 많아질수록 리스트가 사용하는 메모리도 증가한다.

쉽게 구분하면:

```text
시간 복잡도 → 얼마나 오래 걸리는가?
공간 복잡도 → 얼마나 많은 메모리를 사용하는가?
```

### 요약정리
> 시간 복잡도는 입력 데이터가 많아졌을 때 실행 시간이 얼마나 증가하는지를 나타내고, 공간 복잡도는 실행할 때 필요한 메모리가 얼마나 증가하는지를 나타냄
> 예를 들어 반복문 하나는 보통 O(N), 이중 반복문은 O(N²)으로 볼 수 있다.코딩테스트에서는 입력 크기가 클수록 시간 복잡도를 고려해서 효율적인 알고리즘을 선택해야 한다.

**한 줄 핵심**

> **Time Complexity = 실행 효율 / Space Complexity = 메모리 효율**
