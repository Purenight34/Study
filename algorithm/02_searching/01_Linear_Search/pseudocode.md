### 상단 - 방호영 / 순차 검색 (Linear search)
담당 : 방호영

선형 탐색은 리스트의 처음부터 끝까지 순서대로 하나씩 비교하며 원하는 값을 찾는 방식으로 동작하며, 가장 기본적인 탐색 방법이다.

문제
정수 N개가 주어진다. 배열의 앞에서부터 탐색하여 가장 먼저 등장하는 짝수를 찾으시오.

인풋은 정수 N개(N < 100)가 공백을 두고 입력된다.
아웃풋은 입력된 정수들이 공백을 두고 출력된다.
---------------------------------------------
### 중단 - 의사코드
```python
메인 함수
    n = 배열의 길이를 변수 n에 할당한다. 
        for i = 0 부터 n - 1 까지 전체 배열을 순회 
            if arr[i]가 K와 같다면 
                i를 반환 
            K를 찾지 못했다면 
                '없음' 을 반환 
        
메인 함수 끝
```
