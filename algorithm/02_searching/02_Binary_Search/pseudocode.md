### 상단 - binary search(이진 탐색)
담당 : 방호영

binary search(이진 탐색)은 '정렬'된 데이터에서 원하는 값을 빠르게 탐색하는 탐색 알고리즘이다.

문제
이진 탐색(Binary Search)을 이용하여 정수 K가 배열에 존재하는지 탐색하고, 존재한다면 해당 수의 위치를 찾으시오.

인풋
- 첫 번째 줄에는 배열을 입력한다.
- 두 번째 줄에는 찾고자 하는 정수 K를 입력한다.

아웃풋
- 배열에서 K가 위치한 인덱스를 출력한다.
- K가 배열에 존재하지 않는 경우 '없음'을 출력한다.
- 정렬되어있지 않는 배열을 입력했을 경우에도 '없음'을 출력한다.
- 추가로 비교한 횟수도 출력한다.

### 중단 - 의사코드
정렬여부 확인
  for i가 순회하며 인덱스 확인
    i가 i+1보다 크면
      False 반환
  True 반환


왼쪽 수 = 0
오른쪽 수 = 배열의 마지막 인덱스
비교 횟수 = 0
  
메인 함수
    while 왼쪽 수 <= 오른쪽 수
      중간 = (왼쪽 수 + 오른쪽 수)의 합의 절반(혹은 몫)
      비교횟수 1 추가

      if 배열의 중간값이 목표하는 수일 때,
        중간값과 비교횟수 출력
      elif 배열의 중간값이 목표하는 수보다 작을 때,
        왼쪽 수 = 중간값 + 1
      else
        오른쪽 수 = 중간값 - 1
  
    (-1, 비교횟수) 반환

메인함수 끝
